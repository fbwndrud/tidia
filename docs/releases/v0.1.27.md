- **One-command installation:** `claude plugin install tidia --marketplace fbwndrud/tidia` registers the marketplace and installs Tidia for your user account. No separate API key is needed.
- All **12 READMEs** now lead with installation and first use, explain where to run commands, and include updates, automatic updates and removal. Detailed settings, costs and developer checks are expandable.
- English and Korean include a before/after example. The main demo follows the first-use instructions, and the release badge links to the latest published version.
- A release workflow now checks the manifest version, release notes and translated README links and commands before publishing future version tags. ## Install

In your terminal:

```bash
claude plugin install tidia --marketplace fbwndrud/tidia
```

Requires Claude Code 2.1.296+. Restart Claude Code or open a new desktop Code session, then run `/tidia`. Tested on macOS; Linux and Windows are not tested yet.

## Update

```bash
claude plugin marketplace update tidia
claude plugin update tidia@tidia
```

Restart Claude Code to load the update. To enable automatic updates, open `/plugin` → Marketplaces → tidia → Enable auto-update.
