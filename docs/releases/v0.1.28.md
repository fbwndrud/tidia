## Prompts Claude offered are sent as they are

With Claude Code's voice in tap mode (or `voice.autoSubmit`), 0.1.26 started tidying any prompt that appeared in the prompt box in one piece, since that is how a final transcript lands. Prompts Claude itself offered land the same way, so they were tidied too and went out with a raw-transcript note:

- **A reply button in the desktop's next-step box.** Its message is sent as your own Enter, with nothing marking it. Messages like "JSON 키 받았어. 확인하고 옮겨줘." went out reworded ("…옮겨 줘.").
- **A prompt suggestion taken with Tab.** Taking it fires no prompt edit, so it looked like dictation.

Tidia now sends a prompt as it is when it matches a suggestion shown in the prompt box, or a message Claude offered in its last turn (an argument of a tool Claude called, such as a reply button's message). Dictations are still tidied, including speech added after a suggestion you took.

The cleanup model, default settings and privacy behavior are unchanged.

## Install

In your terminal:

```bash
claude plugin install tidia --marketplace fbwndrud/tidia
```

Requires Claude Code 2.1.296+. Restart Claude Code or open a new desktop Code session, then run `/tidia`. Tested on macOS; Linux and Windows are not tested yet.

## Update

```bash
claude plugin marketplace update tidia
claude plugin update tidia@tidia
```

Restart Claude Code to load the update. To enable automatic updates, open `/plugin` → Marketplaces → tidia → Enable auto-update.
