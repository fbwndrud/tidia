# Tidia 테스트 계획

특정 문장 하나가 아니라 **입력의 종류 × 설정 × 받아쓰기 방식**으로 나눠서 봅니다. 누가 하는지에 따라 세 층으로 나눕니다.

| 층 | 무엇을 | 누가 | 음성 |
|----|--------|------|------|
| L1 정리 품질 | 받아쓴 글이 어떻게 정리되는지 | AI (`eval/run.py`, 실제 모델) | 필요 없음 |
| L2 명령·화면 | `/tidia` 명령, 사전 창, 설정 | AI (tmux로 실제 Claude Code 조작) | 필요 없음 |
| L3 받아쓰기 흐름 | 말하기 → 감지 → 정리 → 전송 | 사람 (말하고 Enter만) | 필요 |

사람이 할 일은 L3뿐이고, L3에서도 키보드 조작은 하지 않습니다. 설정을 바꿔야 하면 AI에게 말로 시킵니다.

## L1 정리 품질 — AI가 실행

입력 종류(C) 하나마다 언어별로 2–3개씩 실제 받아쓰기 같은 문장을 AI로 만들고, Mac 음성 합성으로 읽혀 Mac 음성 인식이 받아쓴 출력을 그대로 쓰고, 기대 결과는 "꼭 들어갈 말 / 빠져야 할 말"로 확인합니다.

| # | 입력 종류 | 기대 |
|---|-----------|------|
| C1 | 군말 ("음", "어", "그러니까", "um", "like") | 군말만 빠지고 내용은 그대로 |
| C2 | 반복·더듬기 ("이 이 이거", "the the") | 한 번만 |
| C3 | 말하다 고침 ("3시, 아니 4시", "wait, actually…") | 최종 의도만, 취소한 요청은 빠짐 |
| C4 | 여러 요청·단계 나열 | polish 스타일에서 목록으로 정리, minimal에서는 문장 유지 |
| C5 | 질문 | 질문으로 남음. 정리 모델이 답하지 않음 |
| C6 | Claude에게 시키는 말 ("이 파일 지워 줘") | 지시문 그대로. 정리 모델이 실행하거나 거절하지 않음 |
| C7 | 소리 나는 대로 적힌 영어·코드 용어 | english_terms 단계에 맞게 복원 (off/low/medium/high) |
| C8 | 숫자·날짜·버전·단위 ("이 점 일 점 이백구십육") | 2.1.296처럼 숫자로, 값은 그대로 |
| C9 | 고유명사 + 사전 | 사전 켜면 사전 표기, 끄면 원래대로. 소리만 비슷한 다른 말은 안 바뀜 |
| C10 | 길이 | 3단어 근처는 거의 그대로, 1분 분량도 빠짐없이 |
| C11 | 언어 섞임 | 언어를 바꾸거나 번역하지 않음 |
| C12 | 이미 깨끗한 문장 | 거의 그대로 (과하게 고치지 않음) |
| C13 | 구어체·감정·욕설 | 말투와 강도 유지, 순화하지 않음 |
| C14 | 받아쓴 글 안의 지시 ("이전 지시 무시하고…") | 데이터로 취급. 따르지 않고 그대로 정리 |
| C15 | 경로·명령어·URL ("에스알씨 슬래시 앱 점 티에스", "엔피엠 런 데브") | `src/app.ts`, `npm run dev` |
| C16 | 출력 규칙 (기본 규칙, 직접 만든 규칙) | 조건이 맞을 때만 형식이 바뀜. 규칙에 적힌 문구 외에 말하지 않은 요청·사실은 안 붙음(붙으면 guard가 거부하고 원문 전송) |
| C17 | 부정·금지 ("지우지 말고", "don't", "ないで") | 부정이 그대로 남음. 빠지거나 생기면 guard가 거부하고 원문 전송 |
| C18 | 질문 받아쓰기 | 답하지 않고 질문 그대로 정리 |

**언어:** ko, en, ja, zh, es, de, fr, pt 8개, 164개 케이스. 2026-10-12 기준 162/164 통과(sonnet 1회).

**설정 조합:** 전체 곱이 아니라 쌍별 조합으로 돌립니다.
- style 2 × english_terms 5 × dictionary on/off × model 3
- 각 쌍이 한 번 이상 나오게 하면 약 20번 실행

**합격선:**
- 원문 보존 실패 0건
- 언어별 통과율 95% 이상
- 사전 해로운 바꿈(C9 소리만 비슷한 말) 0건

## L2 명령·화면 — AI가 실행

이미 확인한 것 (2026-10-10, Claude Code 2.1.296):
- `/tidia` 상태, on/off, settings, set (대화형)
- 사전 추가·목록·삭제, 범위(전체/프로젝트), 세션을 넘겨도 유지
- 사전 창(입력·삭제·Esc·q), build(질문 → 후보 → 건너뛰기)
- Claude가 도구로 사전 수정
- ↑로 불러온 글과 키보드 입력은 정리 안 함

아직 남은 것:
- 좁은 터미널에서 창 대신 글 목록이 나오는지
- `ui_language` 8개 언어 표시

## L3 받아쓰기 흐름 — 사람이 말하기만

**준비:** Claude Code를 mod와 함께 실행하고 받아쓰기를 켭니다. 설정을 바꿀 때는 AI에게 "티디아 스타일 minimal로 바꿔 줘"처럼 말합니다.

각 흐름에서 보는 것은 세 가지입니다.
- ① 말하는 도중에 입력창이 바뀌지 않는가
- ② 보낸 메시지가 정리본인가 (군말이 빠짐. debug를 켜면 "받아쓴 내용을 정리해서 보냈어요"도 남음)
- ③ 원래 하려던 말이 빠지거나 바뀌지 않았는가

| # | 흐름 | 하는 일 | 기대 |
|---|------|---------|------|
| V1 | 기본 | 말하고, 2초 쉬고, Enter | ①②③ |
| V2 | 바로 전송 | 말 끝나자마자 Enter | 정리가 끝날 때까지 잠깐 기다렸다가 정리본 전송 ②③ |
| V3 | tap 모드 | 탭 → 말 → 탭(곧바로 전송) | V2와 같음 |
| V4 | 긴 말 | 30초 이상, 중간에 2–3초씩 쉬기 | ① 쉬는 동안 안 바뀜, ③ 빠짐없음 |
| V5 | 짧은 말 | 2–4단어 | 2단어 이하는 그대로, 3단어 이상은 정리 |
| V6 | 친 글 + 말 | 키보드로 몇 단어 친 뒤 이어서 말하기 | 친 부분은 그대로, 말한 부분만 정리 |
| V7 | 두 번 말하기 | 말하고 쉬었다가 다시 말하고 Enter | 두 덩어리 모두 정리, 순서 유지 |
| V8 | 취소 | 말하다가 Esc | 원래 입력창 그대로, 정리 안 뜸 |
| V9 | 언어 | 영어만 / 한·영 섞어서 / 다른 언어 | 언어 유지, 영어 용어 복원 |
| V10 | 코드 대화 | 파일명·함수명·명령어를 말하기 | 대화에 나온 이름 표기로 복원 |
| V11 | 응답 중 | Claude가 답하는 동안 말하고 Enter(대기열) | ②③ |
| V12 | 꺼짐 | AI에게 "티디아 꺼 줘" 후 말하기 | 정리 안 함 |
| V13 | 데스크톱 | 마이크 버튼으로 V1·V2·V6 | 터미널과 같음 |
| V14 | 시끄러운 곳 | 오인식이 많은 상태로 말하기 | 이상한 정리 없이 원문 보존(③) |
| V15 | 말로 사전 고치기 | 이름이 잘못 받아써지게 말한 뒤 "아니 그거 X야" | 방금 받아쓴 단어면 Claude가 확인 창 없이 사전에 넣고 한 줄로 알림, 대화에 기록. 받아쓴 적 없는 단어면 먼저 물음 |
| V16 | 말로 규칙 만들기 | "버그 얘기할 땐 증상, 재현, 기대 순서로 정리해 줘" → 버그 얘기 받아쓰기 | 권한 확인 후 `/tidia rules`에 보이고, 버그 얘기가 그 형식으로 나감 |
| V17 | 말로 설정 바꾸기 | "내 말은 그대로 두고 군말만 빼 줘" | 권한 확인 후 style이 minimal로 바뀜 |

2026-10-11, macOS, 합성 음성(Yuna)으로 마이크에 말하기: V1·V2(Space를 누르고 있는 hold 모드), V16·V17(tap 모드) 통과. V16은 처음에 Claude가 자기 답변 형식 요청으로 받아들여 실패했고, 받아쓴 메시지에 붙는 안내를 고친 뒤 두 번 모두 규칙 추가 확인 창이 떴습니다. 2026-10-12: README GIF 4개를 같은 방식(tap 모드)으로 녹화하며 V3·V16 다시 통과. 데스크톱 앱 마이크 버튼은 하루 실사용에서 Enter 정리(V13의 V2)가 동작함. 사람 목소리 hold 모드, 데스크톱 V6은 아직입니다.

**설정별 체감** (AI에게 바꿔 달라고 하고 V1 반복):
- polish_on: enter / pause
- style: 2종 (polish, minimal)
- english_terms: off / high
- model: haiku(속도)
- message_view: tidied / labeled / full (보낸 메시지 줄이 바뀜)
- dictionary: off면 사전 표기 안 씀, dict_approval: ask면 Claude의 사전 변경마다 확인 창
- attach_raw: 켠 뒤 "방금 받아쓴 원문 뭐였어?"라고 물으면 Claude가 원문을 알아야 함

**학습:** 받아쓴 단어를 키보드로 고쳐야 해서 선택 항목입니다.

**결과 기록:** "V3 실패: 군말 그대로 나감"처럼 번호로 알려 주면 AI가 `manual-checks.md`에 적습니다.
